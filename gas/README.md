# Googleスプレッドシート自動連携 セットアップ手順書

IRON LOG で記録した内容を、手書き用紙と同じフォーマットでGoogleスプレッドシートに自動追記するための設定手順です（所要時間：約3分）。

---

## ステップ 1: スプレッドシートの作成
1. Googleドライブまたは [Googleスプレッドシート](https://sheets.new) を開いて新規スプレッドシートを作成します。
2. スプレッドシート名を任意（例: `筋トレ日誌`）に変更します。

---

## ステップ 2: GASスクリプトの貼り付けとデプロイ
1. スプレッドシートのメニューバーから **「拡張機能」** ＞ **「Apps Script」** をクリックします。
2. 開いたエディタの既存コード（`myFunction`）をすべて消し、`gas/Code.gs` の内容をそのまま貼り付けます。
3. 画面右上の **「デプロイ」** ＞ **「新しいデプロイ」** をクリックします。
4. 歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
5. 以下の通り設定します：
   - **説明**: `IRON LOG 連携`
   - **次のユーザーとして実行**: `自分 (your-email@gmail.com)`
   - **アクセスできるユーザー**: `全員 (Anyone)` ※スマホアプリから安全に送信するために必要です
6. **「デプロイ」** をクリックします。
7. 初回のみ「アクセスの承認」が求められます：
   - 「アクセスを承認」をクリック ＞ 自分のGoogleアカウントを選択
   - 「詳細を表示」をクリック ＞ 「無題のプロジェクト（安全ではないページ）に移動」をクリック ＞ 「許可」をクリック
8. 表示された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

## ステップ 3: アプリへのURL設定
1. Android スマホの Chrome で IRON LOG を開きます。
2. **「設定」** タブを開き、「Googleスプレッドシート自動連携」カードまでスクロールします。
3. **「GAS Web App URL」** 欄に、コピーしたURLを貼り付けます。
4. **「自動記録を有効にする」** スイッチを ON にします。
5. **「接続テスト」** ボタンを押して、「スプレッドシートに正常に送信されました」と出れば完了です！

> [!TIP]
> - 「過去の記録（手書き18件含む）を一括送信」ボタンを押すと、過去のデータもまとめてスプレッドシートに書き込むことができます。
> - 今後は、記録画面で「この内容を保存」を押すたびに、スプレッドシートに新しい行が自動追加されます。
