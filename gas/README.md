# Googleスプレッドシート連携 セットアップ手順書

IRON LOG で記録した内容を、手書き用紙と同じフォーマットでGoogleスプレッドシートに書き込むための設定手順です（所要時間：約3分）。

- 同じ記録を何度送っても行は増えず、上書きされます（シート末尾の「ID」列で見分けます）。
- 送信に失敗したときは、アプリに失敗の理由が表示されます。

> [!IMPORTANT]
> **すでに旧版（v1）を使っている場合**は、下の「旧版からの更新手順」を行ってください。旧版のままだと重複防止が効きません。アプリの「接続テスト」で「GASが旧版です」と表示されたら更新が必要です。

---

## ステップ 1: スプレッドシートの作成
1. Googleドライブまたは [Googleスプレッドシート](https://sheets.new) を開いて新規スプレッドシートを作成します。
2. スプレッドシート名を任意（例: `筋トレ日誌`）に変更します。

---

## ステップ 2: GASスクリプトの貼り付けとデプロイ
1. スプレッドシートのメニューバーから **「拡張機能」** ＞ **「Apps Script」** をクリックします。
2. 開いたエディタの既存コード（`myFunction`）をすべて消し、`gas/Code.gs` の内容をそのまま貼り付けて保存します。
3. 画面右上の **「デプロイ」** ＞ **「新しいデプロイ」** をクリックします。
4. 歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
5. 以下の通り設定します：
   - **説明**: `IRON LOG 連携`
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員` ※ここが「全員」以外だと、アプリから通信できません（アプリに「通信できませんでした」と表示されます）
6. **「デプロイ」** をクリックします。
7. 初回のみ「アクセスの承認」が求められます：
   - 「アクセスを承認」をクリック ＞ 自分のGoogleアカウントを選択
   - 「詳細を表示」をクリック ＞ 「（プロジェクト名）（安全ではないページ）に移動」をクリック ＞ 「許可」をクリック
8. 表示された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

> [!NOTE]
> URL は他の人に教えないでください。URL を知っている人は、このシートに記録を書き込めます。

---

## ステップ 3: アプリへのURL設定
1. スマホの Chrome で IRON LOG（GitHub Pages 版）を開きます。
   - claude.ai の Artifact 版では、セキュリティ制限でGoogleへの通信ができません。Artifact 版では「手動でシートに反映する」を使ってください。
2. **「設定」** タブを開き、「Googleスプレッドシート連携」カードまでスクロールします。
3. **「GAS Web App URL」** 欄に、コピーしたURLを貼り付けます。
4. **「接続テスト」** を押し、「✅ 接続OK（重複防止に対応した最新版）」と出れば完了です。
   - 接続テストではシートに行を書き込みません。
5. 記録のたびに自動で送りたい場合は **「保存時に自動で送る」** を ON にします。

> [!TIP]
> - **「全記録を同期」** で、これまでの記録をまとめて書き込めます。何度押しても行は増えません。
> - 結果はカード内の「最終送信」に表示されます（例：`✅ 全記録の同期：追加3件・更新1件・変更なし15件`）。
> - アプリで記録を削除しても、シートの行は自動では消えません。必要ならシート側で消してください。

---

## 旧版（v1）からの更新手順
1. スプレッドシートの **「拡張機能」** ＞ **「Apps Script」** を開きます。
2. コードをすべて消し、最新の `gas/Code.gs` を貼り付けて保存します。
3. **「デプロイ」** ＞ **「デプロイを管理」** を開き、既存のデプロイの **鉛筆アイコン（編集）** を押します。
4. **「バージョン」** で **「新バージョン」** を選び、**「デプロイ」** を押します。
   - この手順なら **URL は変わりません**。「新しいデプロイ」を作るとURLが変わるので注意してください。
5. アプリで **「接続テスト」** を押し、「最新版」と表示されることを確認します。
6. **「全記録を同期」** を押します。シートに ID 列が追加され、旧版で書いた行は同じ日付の記録に引き継がれます。

### 旧版で2重になった行を消す
旧版では「一括同期」を押すたびに同じ行が追加されていました。更新後、次の手順で片付けられます。

1. スプレッドシートを開き直すと、メニューに **「IRON LOG」** が表示されます（表示されない場合は再読み込み）。
2. **「IRON LOG」** ＞ **「重複した行を削除」** を選びます。
3. 削除される行番号が表示されるので、確認して **「はい」** を押します。
   - 内容がまったく同じ行だけが対象です。同じ日に別の記録として付けた行（IDが違う行）は消しません。
